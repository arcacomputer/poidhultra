# poidh Ultra

An open-source poidh client and shared community backend, built for
[poidh.arca.computer](https://poidh.arca.computer). Existing poidh contracts
remain the authority for bounties and payments. No new bounty contracts are deployed.

Ultra preserves licensed upstream Git history and maintains reviewed integrations.
Cloudflare and Neon are the production adapters; Node, PostgreSQL, and S3-compatible
storage are the self-hosted path. Core workflows require no proprietary identity,
social, or pinning provider.

Implementation and launch validation are in progress. See `docs` for the operating
model and production prerequisites. A production launch sharing community data
with poidh.xyz requires Kenny's integration and a verified, scoped data export.
