# Connecting a Wallet

To use poidh, you'll need to connect a wallet.

You can either connect an existing crypto wallet or create a new wallet directly through poidh.

## Already have a wallet?

Open the wallet menu and connect the wallet you already use.

poidh supports common wallet options such as:

- Rabby
- MetaMask
- Rainbow
- Coinbase Wallet
- WalletConnect

Once connected, you can use that wallet to create bounties, add funds, submit claims, vote, and withdraw rewards.

## Don't have a wallet?

Choose **Create wallet** under **No wallet?** in the wallet picker.

poidh uses **ZeroDev** to create a smart account for you. You can sign up or sign in using:

- Google
- email
- a passkey

You do **not** need to install a browser wallet extension before getting started.

After setup, your ZeroDev account appears in poidh like any other connected wallet.

## Sponsored transactions

poidh currently sponsors the gas for your **first 5 transactions** made through the ZeroDev wallet.

That means you can start using poidh without immediately needing ETH just to pay transaction fees.

The sponsorship covers **gas only**. It does not pay the ETH used to create or contribute to a bounty.

After your first 5 sponsored transactions, you'll need enough ETH on the network you're using to pay normal gas costs.

Examples of actions that may require an onchain transaction include:

- creating a bounty
- contributing to a bounty
- submitting a claim
- voting
- accepting or nominating a claim
- withdrawing funds

## Supported networks

poidh currently supports:

- **Ethereum Mainnet**
- **Base**
- **Arbitrum**

**Degen Chain is retired** and is no longer supported for new poidh activity.

## If you need to add funds

Your wallet will need ETH for bounty funding, contributions, and — after sponsored transactions are used — gas.

If you're using a ZeroDev wallet, poidh's account tools can help you view balances and move or deposit supported assets across supported networks.

## Keep access to your wallet

Whichever option you use, make sure you keep access to the login method or wallet you connected.

If you use an existing wallet, follow that wallet's normal backup and recovery instructions.

If you use ZeroDev, use the same Google account, email, or passkey you used when creating the wallet when you return to poidh.
